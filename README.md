# Rafael Siberón Caraballo

I'm a school librarian and self-taught software developer based in Mayagüez, Puerto Rico.
My work sits at the intersection of education, technology, and public service.

During the day, I manage the library at Escuela David Antongiorgi Córdova under DEPR's
Library Services Program (PSBI). After hours, I build the tools I wish existed — desktop
apps, AI integrations, and data systems designed for real institutional needs in Puerto Rico.

My flagship project, **Suite PSBI**, is a full Python/CustomTkinter library management
system built for deployment across DEPR's school library network. It includes an AI engine
(Llama 3.2), Supabase sync, circulation, dashboards, ID card generation, and an Inno Setup
installer — all developed solo.

I also serve as a Captain in **Civil Air Patrol Puerto Rico Wing**, where I developed the
**CAP UAV Flight Log** — a Windows desktop app for managing drone operations, risk
assessments (CAPF 704R), certifications, and sortie logging.

On the academic side, I'm completing a **Data Science Bootcamp (Terminal34)** alongside
university coursework, with projects in PyTorch, anomaly detection, NLP, and dimensionality
reduction.

I build things that matter to the communities I serve.
